# disappearing_elements

## 북커버 콘셉트 시안

《사라지는 원소들의 시간》 교보 POD 신국판 표지 방향을 검토하기 위한 전면 표지 콘셉트 이미지입니다.

- [시안 1 — 금반지와 원자](cover-concepts/cover_concept_01_gold_ring.png)
- [시안 2 — 반감기의 시간선](cover-concepts/cover_concept_02_timeline.png)
- [시안 3 — 시간을 품은 광물](cover-concepts/cover_concept_03_mineral.png)

현재 이미지는 표지 전면 콘셉트용이며, 최종 POD 파일은 책등 폭과 날개 치수를 반영해 별도 조판합니다.

## 신국판 날개 전체 펼침 시안

아래 이미지는 왼쪽 날개·뒷표지·책등·앞표지·오른쪽 날개를 한 장에 배치한 콘셉트 펼침본입니다. 현재 책 120~125쪽을 기준으로 한 시각 시안이며, 실제 교보 POD 제출 시 용지와 제본 방식에 따른 책등 폭, 재단선, 도련을 적용해야 합니다.
